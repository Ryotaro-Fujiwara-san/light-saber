収縮螺旋筒の中に硬い軸(硬い軸は多段伸縮（テレスコピック）)を入れ、バネで筒と内部で接続。
さらに筒内部にスピーカーを用意。また接触部分が発光するようにする。この時、　 RGB LEDテープライト(ALITOVE LEDテープライト WS2812B)をLEDライトシートを使用して光を均質に拡散させる。発光箇所はセンサー(薄膜圧力センサー (0~20kg)(DF9-40)は厚さ0.25mmの極薄フィルム形状で、螺旋筒とバネの接点や曲面に挟み込んで衝撃位置を検知できます。)で検知する。
